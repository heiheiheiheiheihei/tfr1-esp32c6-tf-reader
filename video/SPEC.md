# TFR-1 介绍片 · SPEC

GOAL: 看完觉得"这人也太闲了，但它真的能挂载"——并且相信屏幕上的东西是真的。
OUTPUT: HyperFrames, 1920×1080, 30 fps
TIME: 52.0 s × 30 = 1560 帧；BPM 120，beat = 0.5 s = 15 帧，bar = 2 s = 60 帧。
      每个镜头的切点都落在 beat（0.5 s 的整数倍）上。

## LOOK

产品自己的语言：这条片子是"一块 172×320 的屏"放大到 1920×1080。

- ground `#050A12`；显示场 `#071320`；面板 `#0A1A2A`；终端 `#01060B`
- ink `#D6ECF5`；次要 `#7C97A8`；**accent `#35E0FF`**（板子自己的青）；mint `#7CFFB2`
  只用于板端 `ONLINE` 状态；red `#FF5F56` 只用于一个 ✗ 和一次删除线
- 像素栅格 4 px；1 px 线 `rgba(53,224,255,.055)`；所有面板边缘对齐 4 px 倍数
- 扫描线 2 px、白色 6% 不透明度，**只**盖在 LCD 面板与照片上（那是"显示屏"这个介质）
- 暗角 8%，无模糊光晕；LCD 面板里的青色是照片/截图自己的亮度，不额外加 bloom
- 字体：中文 `Noto Sans SC`（900/700/500，本地子集 woff2）；等宽 `JetBrains Mono`（400/700）。
  展示字 132 px / 行高 1.06 / 字距 -0.01em；正文 44 px；mono 22–26 px；数字 96–168 px
- 主色 ration：每镜最多一处 `#35E0FF` 的实心块或一个数字

## OBJECTS

1. **TF 卡**：比例 11:15，300×410 px，边缘 1 px 青；8 个触点用去饱和青
   `#7FB9C9`；面上一枚 32×16 的点阵代表 31116288 个扇区的"抽样"，不是装饰。
2. **512 扇区**：32×16 格，格距 8 px，1 格 = 1 个扇区；点亮的那个是主角。
   缩放 4× 后 1024×512。整格移动是这条片子的主线。
3. **TFR1 帧**：`magic "TFR1" | type | flags | seq | len | crc16 | payload`，
   七段等宽方框；payload 里装的就是那个 512 B 方块。
4. **数据通路**：5 个节点 `TF 卡 → ESP32-C6 → USB CDC → 内核 NBD → /dev/nbd0p1`，
   一条总线从中间穿过；节点是 1 px 边框的方框，不是圆角卡片。
5. **终端**：真实转录。`/dev/ttyACM0`、`[nbd] attached /dev/nbd0`、`findmnt`、
   `read 4.00 MiB in 19.20s = 0.21 MiB/s`，全部来自本机现在的真机运行。
6. **LCD 面板**：真机截图 172×320，`image-rendering: pixelated`，3.0× = 516×960（89% 画高）。
7. **真机照片**：706×1366 原片，不重绘、不改色，只做推拉与裁切。

## MOTION

- 进场 `expo.out` 0.45 s；出场 `power2.in` 0.25 s（比进场短 45%）；镜头 `power2.inOut` 0.5 s
- 每镜一个 hero move；其余元素延后 0.1–0.2 s，位移取 hero 的 60%
- 逐个落字：词间 0.07 s，无位移，只有 0→1 与 6 px 模糊归零
- 数字用计数器，帧驱动（不用 setInterval）；终端按字符类型，0.012 s/字符
- 转场：zoom-through（扇区）→ wipe（规格表）→ colour flood（进终端）→
  match cut（截屏→真机）→ dip cut（进声明）。5 种，每种都有画面上的起因
- 静止：标题落位后不再移动；画面里持续运动的只有扇区、终端光标、I/O 曲线

## 事实边界（只允许出现这些）

- ESP32-C6 无 USB OTG / 无 MSC，只有 USB Serial/JTAG 12 Mbps → README、DESIGN §1
- `[nbd] attached /dev/nbd0`、`/dev/nbd0p1` vfat、`findmnt` → host 脚本源码 + README
- `read 4.00 MiB in 19.20s = 0.21 MiB/s` → 本机 2026-11-08 19:2x 真机 `--bench 4`
- `/dev/ttyACM0`、`/dev/nbd0 0B`、`9df…` 无 → 本机实时 `ls` / `lsblk`
- mount 7 s / umount 37 s、0.21 MB/s、只验证 FAT32、需要 Linux+sudo → README 实测表
- 卡：SC16G · 14.84 GiB · 31116288 × 512 B · FAT · 20 MHz → 真机 `--info`
